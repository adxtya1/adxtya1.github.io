Adxtya Gallery

Project Overview

About

Adxtya Gallery is a personal gallery website developed from scratch using HTML, CSS, JavaScript, PHP and MySQL. What started as a simple image gallery has gradually evolved into a feature-rich web application with user accounts, image uploads, favourites, notifications and a complete administration system.

The main objective of this project is to improve my full-stack web development skills by building real-world features while learning modern web technologies.

Technologies Used

  • HTML5
  • CSS3
  • JavaScript
  • PHP
  • MySQL
  • Git & GitHub

Main Features

  • User registration and login system
  • Secure password hashing
  • Responsive desktop and mobile interface
  • Multi-section image gallery
  • Upload images using local files or image URLs
  • Edit, replace and delete uploaded images
  • Favourite (bookmark) system
  • Notification system with unread counter
  • Live website visitor counter
  • Dedicated admin panel
  • Admin upload management
  • Notification management

Project Goals

  • Practice full-stack web development
  • Build real-world PHP and MySQL projects
  • Improve UI and UX design skills
  • Learn backend development through practical implementation
  • Continuously expand the project with new ideas

Future Plans

  • Professional homepage improvements
  • AI-powered features
  • Easter eggs
  • Improved review system
  • Additional user experience improvements
  • Performance optimisations

Development Status

This project is actively maintained and regularly updated. Every new feature represents another step in my learning journey as I continue improving both the website and my web development skills.
